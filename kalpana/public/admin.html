Skillvation product source

Products come from the Skillvation Club Shop and MySkool course APIs. Kalpana validates each sync and publishes a new catalog revision only when products or prices change. A failed sync keeps the current catalog.

Data checks

These come from the shop data itself. Kalpana quotes listed prices; fix anything unexpected in the shop and sync again.

    01 · Attach a source document

    Upload TXT, Markdown, JSON text or PDF up to 1 MB. PDFs are sent to Gemini for extraction. For DOCX/XLSX, export to PDF or text first. Review all extraction before publishing prices.

    02 · Review source documents
    Use these immutable source IDs in product.sourceIds. Only documents referenced by the published catalog are used for customer answers.
    03 · Publish approved pricing
    Amounts use minor currency units: INR 12,000 = 1200000 paise. Set taxBasisPoints (18% = 1800), deliveryAmount, currency, validUntil, compatible add-ons and capacity. Publishing is an administrator approval; use a new revision for every change. This version supports one-time purchases and one core package per quote.
